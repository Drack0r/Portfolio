## 1. Finalité du projet

Concevoir, développer et publier un **portfolio professionnel, fonctionnel et accessible** permettant de démontrer vos compétences techniques et votre capacité à mener un projet de bout en bout.

Le projet doit aboutir à :

- Un site en ligne accessible publiquement
- Une gestion de projet structurée
- Une soutenance orale argumentée

## 2. Choix d’approche technique

### Deux approches possibles

#### 🔹 Approche 1 — Full-code Front-End

- Solution codée 100 % front-end
- Création d’un dépôt GitHub dédié

#### 🔹 Approche 2 — Low-code enrichie

⚠️ **Obligatoire : intégrer au minimum un composant React significatif développé par vous.**

Exemples mentionnés :

- Bannière interactive (Three.js + animations 3D)
- Galerie avec filtres dynamiques
- Formulaire de contact avancé
- Dashboard interactif
- Slider personnalisé

### ⚠️ Restrictions majeures

- ⚠️ Interdiction d’utiliser une solution 100 % no-code (Wix, Webflow sans personnalisation).
- ⚠️ WordPress autorisé uniquement avec personnalisations de code significatives.
- ⚠️ Minimum requis : HTML + CSS.
- ⚠️ Code généré par IA autorisé uniquement s’il est compris, adapté et explicable.

## 3. Gestion de projet

### Mise en place obligatoire d’un Kanban

Colonnes minimales :

- À faire
- En cours
- À tester / Valider
- Terminé

Le tableau doit :

- Contenir des tâches concrètes
- Être mis à jour tout au long du projet
- Permettre un suivi clair

## 4. Contenu du portfolio

### A. Projets de formation (obligatoire)

Présenter un ou plusieurs projets significatifs.

Chaque projet doit inclure :

- Contexte
- Objectifs
- Stack / technologies
- Fonctionnalités réalisées
- Difficultés et solutions
- Résultats / apprentissages

### B. Projets personnels (fortement recommandé)

Permet d’enrichir la crédibilité du portfolio.

### C. Présentation du profil

Sections attendues :

- Accroche / introduction
- Stack technique
- Projets marquants
- Méthodologie
- Engagement / ambition

## 5. Architecture & Design

### Structure principale suggérée

- À propos
- Compétences
- Projets
- Parcours
- Blog / Veille (optionnel)
- Contact

Sections secondaires suggérées :

- Témoignages
- Certifications
- Hobbies
- Ressources

### Design System

Doit inclure :

- Palette de couleurs cohérente
- Typographies hiérarchisées

Wireframes recommandés (non obligatoires).

## 6. SEO

### Démarche demandée

1. Rechercher 3 offres d’emploi pertinentes
2. Identifier les mots-clés récurrents
3. Intégrer ces mots-clés dans :

- `<title>`
- meta description
- titres (H1, H2)
- descriptions de projets

⚠️ Éviter le bourrage de mots-clés.

### Outils de vérification

- Lighthouse
- WAVE
- Screaming Frog

## 7. Accessibilité

Bonnes pratiques minimales :

- Navigation clavier complète
- Focus visible
- HTML sémantique (`main`, `section`, `nav`, `footer`)
- Contrastes suffisants
- Attributs `alt` adaptés
- Labels associés aux champs de formulaire
- Messages d’erreur compréhensibles
- ARIA avec modération

⚠️ Tester avec au moins deux outils parmi :

- Lighthouse
- WAVE
- axe DevTools

## 8. Publication

Le site doit être accessible publiquement.

Plateformes possibles :

- GitHub Pages
- Vercel
- Netlify
- Hébergeur classique

### Vérifications obligatoires

- Responsive (desktop / mobile / tablette)
- Liens fonctionnels
- Formulaires fonctionnels
- Vitesse de chargement
- HTTPS si possible

## 9. Valorisation

Actions demandées :

- Partage sur LinkedIn
- Ajout sur GitHub, CV, plateformes professionnelles
- Contact recruteurs
- Mise à jour régulière

## 10. Livrables & Soutenance

### Livrable

⚠️ Fournir le lien du portfolio en ligne dans un document texte converti en PDF.

Dépôt :

- Dossier ZIP nommé selon le format imposé
- Respect du format de nommage des livrables

### Soutenance (30 minutes)

- 15 min : présentation
- 10 min : discussion
- 5 min : débrief

⚠️ Présentation < 10 min ou > 20 min peut être refusée.

Vous devez présenter :

- Architecture globale
- 2 projets détaillés
- Pitch personnel
- Choix techniques
- Optimisation SEO / accessibilité / performances
- Initiative personnelle complémentaire
